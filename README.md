# ⚡ Smart Electricity Consumption Analyzer

A Streamlit-based web application that helps users calculate and analyze household electricity consumption and estimated electricity bills.

---

## 🚀 Features

- Appliance-wise electricity tracking
- Monthly electricity bill estimation
- Carbon footprint analysis
- Interactive charts and graphs
- Download electricity usage report
- Energy saving suggestions
- Responsive and modern UI

---

## 📊 Functionalities

- Calculates daily electricity consumption
- Estimates monthly electricity usage
- Generates estimated electricity bill
- Displays appliance-wise consumption analysis
- Provides visual insights using charts
